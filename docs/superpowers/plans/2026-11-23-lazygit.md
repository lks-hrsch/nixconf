# lazygit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add lazygit to the client hosts: home-manager `programs.lazygit`, a `:LazyGit` float in nvim, and a tmux popup on `prefix g`.

**Architecture:** One root-level feature file, `modules/lazygit.nix`, supplies three variants (allowed by `.claude/rules/modules.md`): `homeManager.lazygit` (config, `lg` wrapper, tmux popup) and identical `nixos.lazygit` / `darwin.lazygit` (nixvim plugin, keymaps, float fix-ups). Clients pull it in through existing aggregators; servers never import it.

**Tech Stack:** home-manager `programs.lazygit`, nixvim `plugins.lazygit` (kdheepak/lazygit.nvim), stylix lazygit target, tmux `display-popup`. lazygit 0.66.3 (nixpkgs 26.05).

**Spec:** Owner request 2026-11-23 plus answers: clients only, tmux popup on `prefix g`. Background: `docs/lazygit-research.md` (every value below is sourced there).

## Global Constraints

- **Never deploy.** No `nixos-rebuild`/`darwin-rebuild` switch. Hand over the commands in "Hand-over".
- **Clients only:** MacBook-000553, lkshrsch-mb-pro-m1, lkshrsch-workstation, lkshrsch-thinkpad-e590. mercury, deimos, phobos must stay without `plugins.lazygit`.
- `os.editPreset = "nvim-remote"`. Do not set `os.editInTerminal`, `config_file_path`, `use_custom_config_file_path`, and do not install `nvr`.
- `git.overrideGpg = true` (1Password `op-ssh-sign` prompts in a GUI, needs no TTY; also unlocks non-HEAD reword and patch actions).
- `gui.nerdFontsVersion = "3"`.
- No theme settings: stylix `autoEnable` themes lazygit. Any hand-set `gui.theme.*` key needs `lib.mkForce` (lists concatenate otherwise).
- `import-tree` only sees tracked files: `git add modules/lazygit.nix` before any eval.
- No em dashes in code comments.

## Review Focus

1. **Server leak.** A wrong import site ships lazygit to mercury/deimos/phobos. Task 2 Step 5 pins `plugins.lazygit.enable == false` on all three.
2. **Ctrl-h/j/k/l in the nvim float.** vim-tmux-navigator maps them in terminal mode, so lazygit's `<c-j>/<c-k>` (move commit) and `<c-l>` (log menu) die. Task 2's `FileType lazygit` buffer-local `tnoremap` fixes it; manual check in Hand-over.
3. **`e` from the float lands on the wrong tab.** lazygit.nvim re-focuses the pre-float window after nvim-remote opens a tab. Task 2's `TabEnter` + `lazygit_on_exit_callback` fixes it; manual check in Hand-over.
4. **tmux popup cannot find lazygit.** A Ghostty-launched tmux lacks the HM PATH (why the existing `bind A` uses `${config.home.profileDirectory}/bin/claude`). Task 1 uses the absolute path; Task 1 Step 4 asserts it.
5. **git-crypt plaintext.** lazygit's diff panel shows decrypted `secrets/**` (textconv), same as `git diff`. Line staging in git-crypt files is broken upstream (#4196); stage whole files. Document only, no code.

File shape: `_: { flake = let ... in { modules.homeManager.lazygit = ...; }; }`, following `modules/nixvim.nix`. Module args `{ config, ... }`. Contents:

```nix
programs.lazygit = {
  enable = true;
  settings = {
    gui.nerdFontsVersion = "3";
    os.editPreset = "nvim-remote";

  };

  bind g display-popup -E -d "#{pane_current_path}" -w 90% -h 90% "${config.home.profileDirectory}/bin/lazygit"
'';
```

`shellWrapperName` stays `lg`; zsh integration is on by default.

Manual checks after switch:

1. `lazygit -cd` prints `~/.config/lazygit`.
2. nvim `<leader>gg`: in the Commits panel, `<c-j>` moves a commit and `<c-l>` opens the log menu (Review Focus 2).
3. In the float, `e` on a file closes lazygit and leaves you on the file's tab (Review Focus 3).
4. `prefix g` in tmux opens the popup in the pane's directory; `<c-j>` moves a commit there (tmux hands popup keys to the popup job before any key table, `server-client.c` overlay_key, so `<c-j>` reaches lazygit); `e` opens a nested nvim in the popup.
5. Commit in lazygit: one 1Password prompt, commit shows as signed (`git log --show-signature -1`).
6. Leave lazygit open for 2 minutes: if 1Password asks to approve the SSH key every ~60 s, that is `git.autoFetch` (default on, `refresher.fetchInterval: 60`). Fix by setting `git.autoFetch = false`.
